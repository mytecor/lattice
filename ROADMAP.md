# Роадмап Lattice

Роадмап разложен по трём уровням в [`roadmap/`](./roadmap/README.md):

1. **План (верхнеуровневый)** — [`roadmap/VISION.md`](./roadmap/VISION.md): куда идём,
   вехи, без технических деталей.
2. **Фичи** — у каждой фичи свой каталог [`roadmap/<feature-id>-<feature-slug>/`](./roadmap/features/README.md),
   где лежат и файл фичи, и её задачи; индекс — [`roadmap/features/README.md`](./roadmap/features/README.md).
3. **Задачи** — отдельный файл на задачу внутри каталога своей фичи; реестр —
   [`roadmap/tasks/README.md`](./roadmap/tasks/README.md), шаблон —
   [`roadmap/tasks/TEMPLATE.md`](./roadmap/tasks/TEMPLATE.md).

Открытые решения и отложенное — в [`roadmap/BACKLOG.md`](./roadmap/BACKLOG.md).

Начать чтение лучше с [`roadmap/README.md`](./roadmap/README.md).
