# node-status

Go-сервис статуса узла. Слушает только loopback, сохраняет совместимый JSON на `/`, отдаёт
`/healthz` и Prometheus text exposition на `/metrics`.

Метрики покрывают CPU, load average, память и swap, корневую файловую систему, блочные устройства,
сетевые интерфейсы, thermal zones, uptime, ошибки сборщика, а также состояние и число рестартов
ограниченного набора systemd-юнитов. Лейблы содержат только ограниченные множества (`device`,
`mode`, `unit`, `state`, `type`); hostname, IP, commit и другие изменчивые значения не используются
как измерения временных рядов, кроме одиночной build-info серии.
