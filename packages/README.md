# Lattice Packages

Каталог `packages/` хранит пакеты, которых нет в общем репозитории Nix, локальные изменения, патчи и сборки внешних зависимостей

Каждый пакет живет в отдельной директории и экспортирует свой `flake.nix`, который предоставляет `packages.${system}.default` output

Пример можно посмотреть в [example/](./example/flake.nix)
