# Packages

Каталог `packages/` хранит локальные конфиги пакетов и оверлеи для Nix

## Назначение

Слой нужен для пакетов, которых нет в общем репозитории Nix, либо для локальных изменений и сборки внешних зависимостей

## Что хранить

- локальные `overlay`
- derivation-описания
- patched packages
- сборочные обертки для внешних инструментов

## Что не хранить

- конфигурации сервисов
- роли нод
- hardware
- node-specific данные
- секреты

## Правило

Пакеты должны быть максимально изолированы от логики `modules/` и `profiles/`
