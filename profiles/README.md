# Profiles

Каталог `profiles/` хранит пресеты и роли, собранные из модулей

## Назначение

Профиль объединяет несколько модулей в одну повторяемую роль и избавляет от копипасты в `nodes/<name>`

## Что делает профиль

- импортирует нужные модули из `modules/`
- включает их с согласованными значениями по умолчанию
- задает общие параметры роли
- упрощает подключение одного и того же набора сервисов в разных нодах

## Что не делает профиль

- не определяет hardware
- не содержит нодовых секретов
- не хранит локальные файлы конкретной машины
- не дублирует код модулей

## Рекомендуемые профили

- `base`
- `reticulum-node`
- `admin-access`
- `storage-node`

## Правило

Профиль должен быть композиционным и переиспользуемым в разных нодах
