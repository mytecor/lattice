# Lattice Hardware

Каталог `hardware/` хранит конфигурации железа
Здесь находятся параметры, зависящие от конкретного устройства или класса устройств

## Правило

Один каталог в `hardware/` должен описывать один тип платформы или одно конкретное устройство и содержать собственный `flake.nix`, предоставляющий `hardware.nixosModule` output
