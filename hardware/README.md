# Lattice Hardware

Каталог `hardware/` хранит конфигурации железа
Здесь находятся параметры, зависящие от конкретного устройства или класса устройств

## Правило

Один каталог в `hardware/` описывает один тип платформы или конкретное устройство и содержит
`default.nix` — обычный NixOS-модуль. Корневой flake подключает его как input с `flake = false`.
