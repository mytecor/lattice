# F3. Секреты и идентичность узла

Безопасность сети держится на ключах, а не на закрытости конфигов. Секреты уходят из
репозитория, появляется процедура bootstrap, ротации и отзыва. Соответствует [вехе 2](../VISION.md#вехи-порядок-без-деталей).

Задачи: [f2-01](../tasks/f2-01-secrets-tool.md),
[f2-02](../tasks/f2-02-node-identity.md),
[f2-03](../tasks/f2-03-secret-bootstrap.md),
[f2-04](../tasks/f2-04-replace-dummy-secrets.md),
[f2-05](../tasks/f2-05-key-rotation.md).

**Критерий готовности:** репозиторий можно опубликовать целиком, и это не даёт доступа ни к
одному узлу.
