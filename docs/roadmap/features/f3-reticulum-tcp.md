# F3. Reticulum поверх TCP/IP и удалённый доступ

Узлы связываются через интернет, а не только в LAN, и доступны администратору по RNS-адресу
даже за NAT. Соответствует [вехе 3](../VISION.md#вехи-порядок-без-деталей).

Задачи: [f3-01](../tasks/f3-01-reticulum-tcp-interfaces.md),
[f3-02](../tasks/f3-02-define-entry-points.md),
[f3-03](../tasks/f3-03-second-node-rnsh.md),
[f3-04](../tasks/f3-04-rnsh-nat-access.md).

**Критерий готовности:** с ноутбука через rnsh открывается shell на узле за NAT, связь переживает
смену IP на стороне клиента.

**Статус:** TCP-интерфейсы и дефолты профиля реализованы в
[f3-01](../tasks/f3-01-reticulum-tcp-interfaces.md); генерация конфигурации и локальное TCP-соединение
проверены. Следующий шаг — выбрать точку входа и способ распространения её адреса в
[f3-02](../tasks/f3-02-define-entry-points.md). Интернет-связность и rnsh за NAT ещё не проверены.
