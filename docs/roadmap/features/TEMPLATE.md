# Шаблон фичи

Скопируйте этот файл в `docs/roadmap/features/<id>-<slug>.md` и заполните. `<id>` — номер вида
`f7` (порядковый номер фичи), `<slug>` — короткое имя. Пример: `f7-wireless-nodes.md`.

Затем добавьте строку фичи в [`features/README.md`](./README.md), ссылку на неё из нужной
[вехи](../VISION.md#вехи-порядок-без-деталей) и заведите задачи в
[`tasks/`](../tasks/README.md) по [TEMPLATE.md](../tasks/TEMPLATE.md).

> Порядок фич в роадмапе задаётся зависимостями, а не календарём. Новую фичу ставьте после тех,
> на которые она опирается, и только когда увидите реальную потребность, которой не покрывают
> F1–F6.
