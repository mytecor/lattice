# Шаблон фичи

Скопируйте этот файл в `docs/roadmap/<feature-id>-<feature-slug>/README.md` и заполните.
`<feature-id>` — номер фичи (вида `f7`), `<feature-slug>` — короткий слаг фичи; каталог называется
по имени файла фичи. Пример: `docs/roadmap/f7-wireless-nodes/README.md`.

Затем добавьте строку фичи в [`features/README.md`](./README.md), ссылку на неё из нужной
[вехи](../VISION.md#вехи-и-зависимости-без-деталей) и заведите задачи в том же каталоге
по [шаблону задачи](../tasks/TEMPLATE.md).

> Номер фичи — стабильный идентификатор, а каталог называют по имени файла фичи
> (`<feature-id>-<feature-slug>/`). Порядок реализации задаётся явными зависимостями, а не номером
> или календарём. Новую фичу заводите только для потребности, которую не покрывают уже
> существующие вертикали.
