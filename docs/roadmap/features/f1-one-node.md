# F1. Одна железная нода в работе

Первая веха ([веха 1](../VISION.md#вехи-и-зависимости-без-деталей)): проект перестаёт быть только
проектом. Первая реальная нода `mytecor-homelab` на Intel N100 ставится с нуля, переживает
перезагрузку и сама применяет коммит из `main`.

Физическая машина до миграции называется `byurik`. После миграции она становится
`mytecor-homelab`; это одна и та же первая нода, а не две разные ноды сети.

Задачи: [f1-01](../tasks/f1-01-assemble-base-profile.md),
[f1-02](../tasks/f1-02-unify-module-profile-model.md),
[f1-03](../tasks/f1-03-bootstrap-intel-n100.md),
[f1-04](../tasks/f1-04-verify-comin-github.md).

**Критерий готовности:** узел установлен с нуля по документации, использует подключаемый модуль
стираемого root, переживает перезагрузку, сохраняет только объявленное состояние, самостоятельно
подключается к Wi-Fi и применяет коммит из `main` без участия администратора. Штатная миграция
после её запуска не требует настройки Wi-Fi или административного доступа на локальной консоли.

**Осознанно откладываем:** вторую ноду, radicle-remote в comin и все реальные секреты, кроме
необходимых для единственного Wi-Fi-подключения `mytecor-homelab`.
