# F5. Внешние узлы

Граница узла чистая: конфигурация может жить вне этого репозитория, а сеть — принять узел без
раскрытия чужих секретов. Соответствует [вехе 5](../VISION.md#вехи-порядок-без-деталей).

Задачи: [f5-01](../tasks/f5-01-external-node-repo.md),
[f5-02](../tasks/f5-02-trust-policy.md),
[f5-03](../tasks/f5-03-contributing-guide.md).

**Критерий готовности:** узел из внешнего репозитория участвует в сети и не имеет доступа к
секретам других узлов.
