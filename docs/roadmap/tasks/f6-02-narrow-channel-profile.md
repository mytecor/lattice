# Проверить сервисы на узком канале; вынести в отдельный профиль

Фича: [F6 — радио и mesh](../FEATURES.md).

## Контекст

Радио — узкий канал. Нужно проверить, что сервисы, написанные на F2–F4, работают на узком канале
и вынести в отдельный профиль то, что не работает.

## Что сделать

- [ ] Проверить работу сервисов F2–F4 поверх радиоинтерфейса.
- [ ] Вынести в отдельный профиль те, что не работают на узком канале (или ограничить их).
- [ ] Задокументировать результат в README затронутого профиля.

## Критерий готовности

- [ ] Понятно, какие сервисы работают на узком канале, а какие вынесены в отдельный профиль.

## Затрагиваемые файлы / слои

- `profiles/` (новый профиль для узкого канала)
- `modules/` задействованных сервисов
