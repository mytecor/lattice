# Довести `CONTRIBUTING.md` до инструкции для постороннего человека

Фича: [F5 — внешние узлы](../FEATURES.md).

## Контекст

Целевое состояние: «новый узел разворачивается по документации человеком, который не участвовал в
разработке» (см. [VISION.md](../VISION.md)). Нужно довести `CONTRIBUTING.md` до инструкции, по
которой посторонний поднимает свой узел и подключает его к сети.

## Что сделать

- [ ] Дополнить `CONTRIBUTING.md` пошаговой инструкцией для нового участника.
- [ ] Опираться на чистую границу узла ([f5-01](./f5-01-external-node-repo.md)) и политику
      доверия ([f5-02](./f5-02-trust-policy.md)).
- [ ] Проверить инструкцию на человеке, не участвовавшем в разработке.

## Критерий готовности

- [ ] Посторонний человек поднимает свой узел по `CONTRIBUTING.md` без участия авторов.
