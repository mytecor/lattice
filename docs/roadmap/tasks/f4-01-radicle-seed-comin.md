# Radicle-seed на нескольких узлах; `comin` на radicle-remote

Фича: [F4 — полезная нагрузка](../features/f4-payload.md).

## Контекст

Цель F4: конфигурация сети распространяется между узлами без GitHub. Нужно поднять Radicle-seed
на нескольких узлах, переключить `comin` на radicle-remote как основной источник, GitHub оставить
зеркалом. Отдельно решить проблему первичной загрузки: узел должен получить radicle-хранилище до
того, как сможет тянуть из него конфиг.

## Что сделать

- [ ] Поднять Radicle-seed на нескольких узлах (`profiles/radicle`).
- [ ] Переключить `comin` на radicle-remote как основной источник, GitHub — зеркало.
- [ ] Решить проблему первичной загрузки radicle-хранилища на новый узел.

## Критерий готовности

- [ ] Конфиг сети распространяется между узлами без GitHub.
- [ ] Новый узел получает radicle-хранилище и сам обновляется из него.

## Затрагиваемые файлы / слои

- `nodes/`
