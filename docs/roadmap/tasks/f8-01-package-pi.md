# Упаковать и закрепить Pi

Фича: [F8 — интерактивный Pi runtime](../features/f8-pi-runtime.md). Зависит от F7.

## Контекст

Pi должен устанавливаться и обновляться тем же декларативным способом, что и остальная NixOS-нода.

## Что сделать

- [ ] Закрепить источник и версию Pi.
- [ ] Добавить package/module/profile без пользовательской ручной установки.
- [ ] Зафиксировать совместимые runtime dependencies и upgrade procedure.
- [ ] Добавить smoke check запуска CLI/TUI.

## Критерий готовности

- [ ] Pi появляется после rebuild и запускается на чистом пользовательском профиле.
- [ ] Версия и зависимости воспроизводятся из flake lock state.

## Затрагиваемые файлы / слои

- `flake.nix`, `flake.lock`
- `modules/pi/`
- `profiles/pi/`
