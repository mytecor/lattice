# Описать процедуру bootstrap секрета узла

Фича: [F2 — секреты и идентичность](../features/f2-secrets-identity.md).

## Контекст

Цель F3: «узел ставится без ручного копирования файлов сверх одного ключа» (см.
[VISION.md](../VISION.md)). Нужно описать, как ключ попадает на узел при первой установке.

## Что сделать

- [ ] Описать, как ключ секретов попадает на узел при первой установке (единственный
      передаваемый вручную файл).
- [ ] Зафиксировать процедуру в `DEPLOYMENT.md` и/или `ARCHITECTURE.md`.
- [ ] Проверить bootstrap на чистом узле с нуля.

## Критерий готовности

- [ ] Новый узел ставится с нуля, получая ровно один ключ вручную.
- [ ] Bootstrap описан по шагам и воспроизводим.

## Затрагиваемые файлы / слои

- `DEPLOYMENT.md`, `ARCHITECTURE.md`
- `profiles/` (профиль секретов)

## Открытые вопросы

Зависит от инструмента [f2-01](./f2-01-secrets-tool.md) и идентичности
[f2-02](./f2-02-node-identity.md).
