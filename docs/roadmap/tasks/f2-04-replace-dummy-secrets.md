# Заменить секреты-заглушки на реальную схему

Фича: [F2 — секреты и идентичность](../features/f2-secrets-identity.md).

## Контекст

Сейчас в репозитории лежат заглушки: `dummy-key-for-vm` в radicle, `fakeWirelessSecret` в конфиге
узла. Их нужно заменить на реальную схему секретов, а в `nodes/example` оставить заведомо
тестовые значения с явной пометкой.

## Что сделать

- [ ] Заменить `dummy-key-for-vm` на реальный секрет через выбранную схему.
- [ ] Заменить `fakeWirelessSecret` в конфиге узла.
- [ ] Пометить в `nodes/example` тестовые значения явным образом (если остаются).
- [ ] Проверить, что ни один реальный секрет не попал в репозиторий.

## Критерий готовности

- [ ] Реальные секреты узла не лежат в репозитории в открытом виде.
- [ ] Оставшиеся тестовые значения в `nodes/example` явно помечены.

## Затрагиваемые файлы / слои

- `profiles/radicle`
- `nodes/example/` (секреты/конфиг)
- `modules/wireless`
