# Заменить секреты-заглушки на реальную схему

Фича: [F2 — секреты и идентичность](../features/f2-secrets-identity.md).

## Контекст

В профиле Radicle был фиктивный `services.radicle.publicKey`, а Wi-Fi шаблонной ноды создавался
через `pkgs.writeText`. Публичный ключ не является секретом: его задаёт нода, а отдельный закрытый
ключ должен поступать через `agenix`. В `nodes/example` допустимы только явно тестовые значения.

## Что сделать

- [x] Удалить фиктивный публичный ключ Radicle; подключить закрытый ключ через
      `config.age.secrets.radicle-private-key.path`.
- [x] В `nodes/mytecor-homelab` передать реальные SSID и пароль путями
      `config.age.secrets.*.path`.
- [x] Оставить `nodes/example` только шаблоном и явно пометить его Wi-Fi-значения как тестовые.
- [x] Проверить текущие файлы и историю Git на открытые секреты.

## Критерий готовности

- [x] Реальные секреты узла не лежат в репозитории в открытом виде.
- [x] Оставшиеся тестовые значения в `nodes/example` явно помечены.

## Результат

Выполнено 2026-09-04. Wi-Fi и опциональный хеш пароля root у `mytecor-homelab` уже используют
зашифрованные `.age`-файлы. `nodes/example` явно помечен как тестовый в коде и README.

Профиль Radicle требует публичный ключ от ноды и передаёт runtime-путь закрытого ключа из
`agenix` в systemd `LoadCredential`; HTTP gateway не получает этот credential.
Контракт настройки описан в [`profiles/radicle/README.md`](../../../profiles/radicle/README.md).
После закрытия этой задачи профиль был подключён к `mytecor-homelab` в
[f4-01](./f4-01-radicle-seed-comin.md): отдельная реальная пара доставлена через `agenix`, а
запуск и соответствие закрытого ключа публичному проверены на работающей ноде.

Проверки:

- `nix flake check --no-build --all-systems` — успешно; сборка Linux-систем не запускалась.
- Отдельная оценка конфигурации с профилем Radicle подтвердила `LoadCredential`, права секрета
  и отсутствие закрытого ключа у HTTP gateway. Без публичного ключа или объявления секрета
  конфигурация отклоняется. Использовались только тестовые данные для оценки, без запуска сервиса.
- Gitleaks 8.30.1 не нашёл утечек в текущих файлах проекта и 19 коммитах доступной истории Git.
- Открытые значения трёх секретов homelab дополнительно сверены с текущими файлами и Git blobs
  всей доступной истории без вывода значений и записи расшифрованных данных на диск.
  Проверка относится к доступному состоянию репозитория, а не к будущим изменениям.
