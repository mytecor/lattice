# Довести идею `MSG_BUS.md` до модуля

Фича: [F6 — радио и mesh](../features/f6-radio-mesh.md).

## Контекст

[MSG_BUS.md](../../../MSG_BUS.md) описывает идею mesh-шины поверх Reticulum. Доводить её до модуля
стоит только если она к этому моменту ещё нужна — по критерию F6 (радио-связь между узлами) и
после проверки сервисов на узком канале ([f6-02](./f6-02-narrow-channel-profile.md)).

## Что сделать

- [ ] Оценить, нужна ли mesh-шина после F2–F4 (сверх того, что уже даёт Reticulum).
- [ ] Если нужна — превратить идею из `MSG_BUS.md` в модуль и профиль.
- [ ] Если нет — закрыть вопрос и зафиксировать, почему.

## Критерий готовности

- [ ] Идея либо реализована как модуль, либо обоснованно отклонена.

## Затрагиваемые файлы / слои

- `modules/` (новый модуль), `MSG_BUS.md`

## Открытые вопросы

Нужно ли это вообще — решается по итогам F2–F6.
