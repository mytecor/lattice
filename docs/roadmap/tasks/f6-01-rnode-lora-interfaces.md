# Добавить интерфейсы RNode/LoRa в слой интерфейсов Reticulum

Фича: [F6 — радио и mesh](../FEATURES.md).

## Контекст

Радио добавляется как ещё один интерфейс к уже работающей сети (см. [VISION.md](../VISION.md);
транспорт — не отдельный этап). Нужно добавить интерфейсы RNode/LoRa в слой интерфейсов
Reticulum, не трогая конфигурацию сервисов.

## Что сделать

- [ ] Добавить интерфейс RNode/LoRa в `modules/rns-server` / слой интерфейсов Reticulum.
- [ ] Убедиться, что смена транспорта не требует правок в конфигурации сервисов.

## Критерий готовности

- [ ] Узел поднимает RNode/LoRa-интерфейс, сервисы при этом не меняются.

## Затрагиваемые файлы / слои

- `modules/rns-server`, `profiles/rns-server`
- `hardware/` (если требует драйвер/железо)
