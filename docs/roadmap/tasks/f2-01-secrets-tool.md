# Ввести инструмент секретов (sops-nix или agenix)

Фича: [F2 — секреты и идентичность](../features/f2-secrets-identity.md).

## Контекст

Инвариант: «конфигурация публична, секреты — нет», безопасность держится на ключах. Нужно
выбрать инструмент управления секретами и зафиксировать выбор в `ARCHITECTURE.md`.

## Что сделать

- [ ] Сравнить sops-nix и agenix для сценария Lattice (pull-based, ключи на узле).
- [ ] Выбрать один инструмент и зафиксировать решение в `ARCHITECTURE.md`.
- [ ] Подключить выбранный инструмент как модуль/профиль.

## Критерий готовности

- [ ] Инструмент выбран и задокументирован в `ARCHITECTURE.md`.
- [ ] Базовая схема шифрования секретов работает в сборке.

## Затрагиваемые файлы / слои

- `modules/`, `profiles/` (новый профиль секретов)
- `ARCHITECTURE.md`
