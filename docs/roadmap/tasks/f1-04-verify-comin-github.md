# Убедиться, что `comin` тянет из GitHub и применяет конфиг узла

Фича: [F1 — одна железная нода](../FEATURES.md).

## Контекст

`profiles/gitops` включает `comin`, нацеленный на GitHub и локальный путь Radicle-хранилища. На
этой задаче проверяется основной pull-based путь: узел сам применяет коммит из `main` без
участия администратора.

## Что сделать

- [ ] Убедиться, что `comin` на узле опрашивает `https://github.com/mytecor/lattice.git`, ветку
      `main`.
- [ ] Применить коммит к конфигу узла и проверить, что узел подхватил его сам (без
      `nixos-rebuild --target-host`).
- [ ] Проверить, что локальный Radicle-path в списке источников не мешает GitHub-пути.

## Критерий готовности

- [ ] Коммит в `main` применяется на узле автоматически, без ручного вмешательства.

## Затрагиваемые файлы / слои

- `profiles/gitops`
- `nodes/<первый-узел>`
