# Убедиться, что `comin` тянет из GitHub и применяет конфиг узла

Фича: [F1 — одна железная нода](../features/f1-one-node.md).

## Контекст

`profiles/gitops` включает `comin`, нацеленный на GitHub и локальный путь Radicle-хранилища. На
этой задаче проверяется основной pull-based путь: узел сам применяет коммит из `main` без
участия администратора.

## Что сделать

- [x] Убедиться, что `comin` на узле опрашивает `https://github.com/mytecor/lattice.git`, ветку
      `main`.
- [x] Применить коммит к конфигу узла и проверить, что узел подхватил его сам (без
      `nixos-rebuild --target-host`).
- [x] Проверить, что локальный Radicle-path в списке источников не мешает GitHub-пути.

## Критерий готовности

- [x] Коммит в `main` применяется на узле автоматически, без ручного вмешательства.

## Результат проверки

Проверено на работающем узле: GitHub remote применяется автоматически, наличие локального
Radicle-path не блокирует обновление.

- `nodes/<первый-узел>`
