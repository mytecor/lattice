# Описать процедуру ротации и отзыва ключа

Фича: [F3 — секреты и идентичность](../FEATURES.md).

## Контекст

На случай компрометации узла нужна процедура ротации ключа и отзыва доступа скомпрометированного
узла — чтобы сеть могла исключить его без остановки.

## Что сделать

- [ ] Описать ротацию ключа секретов узла.
- [ ] Описать отзыв ключа скомпрометированного узла и исключение его из сети.
- [ ] Зафиксировать обе процедуры в документации (`ARCHITECTURE.md` / `CONTRIBUTING.md`).

## Критерий готовности

- [ ] Процедура ротации и отзыва описана по шагам и воспроизводима.

## Затрагиваемые файлы / слои

- `ARCHITECTURE.md`, `CONTRIBUTING.md`
- `profiles/` (профиль секретов)

## Открытые вопросы

Зависит от идентичности [f3-02](./f3-02-node-identity.md) и инструмента
[f3-01](./f3-01-secrets-tool.md).
