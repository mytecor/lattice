# Описать процедуру bootstrap секрета узла

Фича: [F2 — секреты и идентичность](./README.md).

## Контекст

Цель F2: «узел ставится без ручного копирования файлов сверх одного ключа» (см.
[VISION.md](../VISION.md)). Нужно описать, как ключ попадает на узел при первой установке.

## Что сделать

- [x] Описать, как ключ расшифрования `agenix` попадает на узел при первой установке (единственный
      передаваемый файл). Для доступной ноды он передаётся удалённо до переключения системы.
- [x] Зафиксировать процедуру в `DEPLOYMENT.md` и/или `ARCHITECTURE.md`.
- [x] Проверить bootstrap на `mytecor-homelab` при её первой установке с нуля.
- [x] Проверить, что штатный bootstrap не требует настройки Wi-Fi или SSH на локальной консоли.
- [x] Проверить, что после bootstrap нода обнаруживается по заранее известному адресу или mDNS.

## Критерий готовности

- [x] Новый узел ставится с нуля, получая ровно один ключ по заранее доступному защищённому каналу.
- [x] После начала переключения Wi-Fi и административный доступ не требуют локальной настройки.
- [x] Bootstrap описан по шагам и воспроизводим.
