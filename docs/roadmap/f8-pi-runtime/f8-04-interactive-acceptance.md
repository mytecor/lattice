# Провести интерактивную acceptance-проверку Pi

Фича: [F8 — интерактивный Pi runtime](./README.md). Зависит от f8-02 и f8-03.

## Контекст

Конфигурация считается рабочей только после реальной разработки на основной ноде, а не после
запуска пустого TUI.

## Что сделать

- [ ] Из чистого checkout запустить Pi TUI и выполнить ограниченную реальную задачу.
- [ ] Использовать bash/git/project tools и logical model через gateway.
- [ ] Зафиксировать входы, созданный commit/result и наблюдаемые логи без секретов.
- [ ] Повторить запуск после rebuild или очистки user-local Pi state.

## Критерий готовности

- [ ] Задача завершена воспроизводимым результатом без прямых provider credentials.
- [ ] Очистка Pi session не делает repository state непригодным для продолжения.
