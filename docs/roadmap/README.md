# Роадмап Lattice

Это указатель на роадмап, разложенный по уровням. Верхнеуровневый план и детали живут в разных
файлах, чтобы читать можно было с нужной глубины, не таща весь контекст сразу.

## Три уровня

| Уровень | Файл | Для кого | Что внутри |
| ------- | ---- | -------- | ---------- |
| **1. План** | [VISION.md](./VISION.md) | кто хочет понять, куда идём | цель, масштаб, транспорт, вехи, инварианты — без технических деталей |
| **2. Фичи** | [FEATURES.md](./FEATURES.md) | кто планирует работу | фичи F1–F6 с задачами и критериями готовности |
| **3. Задачи** | [`tasks/`](./tasks/README.md) | кто делает | отдельный файл на задачу + шаблон |

## Как пользоваться

- **«Что вообще происходит?»** — прочитайте `VISION.md`.
- **«Что за работа ближе всего?»** — `FEATURES.md` (фичи по зависимостям) и реестр задач.
- **«За что берусь?»** — откройте конкретный файл в `tasks/`.
- **«Завожу новую задачу»** — скопируйте [TEMPLATE.md](./tasks/TEMPLATE.md).

## Статус

Проект на этапе проектирования: активна работа над **F1 — одна железная нода**. Незакрытые
вопросы отслеживаются в [BACKLOG.md](./BACKLOG.md); работа идёт рывками, поэтому `main` всегда
собирается.
