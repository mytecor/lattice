# Принять путь от обсуждения к автономной фиче

Фича: [F20 — planning loop](./README.md). Зависит от [f20-01](./f20-01-task-authoring.md);
полная приёмка использует [F21](./../f21-multi-agent/README.md) и
[F22](./../f22-git-trunk-review/README.md).

## Что сделать

- [ ] Прервать незавершённое обсуждение, сохранить сжатый драфт в отдельной ветке и восстановить
      его другой сессией root; проверить отсутствие запуска planner и исполнителей до команды.
- [ ] По явному старту выполнить отдельного planner и принять фичу с иерархией задач, docs и
      системными review-задачами без прямого push в `main` от агента.
- [ ] Закрыть сессию root после старта и подтвердить автономное продвижение.
- [ ] Изменение цели довести по иерархии до человека; после его решения root публикует уточнение.
- [ ] Пройти полный lifecycle с F21: независимые checks/review, принятие задач, docs, итоговое
      review фичи и удаление только её завершённых рабочих файлов.

## Критерий готовности

- [ ] Воспроизводимы `обсуждение → draft → явный старт → planner → Git-план → автономная работа`.
- [ ] Драфт, заблокированная или ещё не принятая фича не удаляются как завершённые.

## Результат приёмки

Runbook должен различать проверку планирования и полную вертикаль F21–F23; завершённый runtime
turn сам по себе не считается успешным выполнением фичи.
