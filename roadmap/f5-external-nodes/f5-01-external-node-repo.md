# Вынести узел в отдельный репозиторий как внешний input

Фича: [F5 — внешние узлы](./README.md).

## Контекст

Цель F5: чистая граница узла. Нужно вынести хотя бы один узел в отдельный репозиторий и
подключить его в корневой flake как внешний input, чтобы проверить, что граница узла действительно
чистая.

## Что сделать

- [ ] Вынести узел в отдельный Git-репозиторий (как самостоятельный flake).
- [ ] Подключить его в корневой flake как внешний input.
- [ ] Проверить сборку и обновление узла через корневой агрегатор.

## Критерий готовности

- [ ] Узел из внешнего репозитория собирается через корневой flake.

## Затрагиваемые файлы / слои

- Корневой `flake.nix` (агрегатор нод)
- Внешний репозиторий узла
