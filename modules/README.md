# Modules

Каталог `modules/` хранит NixOS-модули сервисов, запускаемых на нодах Lattice

## Назначение

Модуль описывает один сервис или одну логическую подсистему. Все модули должны иметь единый контракт через `options.lattice.<name>`

## Общие принципы

- один модуль = один сервис или одна подсистема
- модуль не знает, к какой ноде он подключен
- параметры модуля экспортируются через `options.lattice.<name>`
- нодовая специфика хранится в `nodes/`
- повторяемые комбинации сервисов собираются в `profiles/`

## Общие опции

- `enable`
- `package`
- `user`
- `group`
- `port`
- `dataDir`
- `settings` или `configFile`
- `openFirewall`
- `extraArgs`
- `environment`
- `secrets`

## Правило

Модуль не должен дублировать composition-логику профилей и не должен хранить секреты
